# 마이링크(MyLink) — 기능 정의서 (PRD)

> **버전**: v1.0  
> **작성일**: 2026-10-09  
> **언어**: 한국어  
> **플랫폼**: 웹 브라우저 (PC / 모바일 반응형)

---

## 1. 서비스 개요

### 1.1 서비스 목적
**마이링크**는 누구나 실시간 라이브 방송을 진행하고, 시청자는 카테고리 기반으로 원하는 방송을 쉽게 찾아 시청할 수 있는 **한국어 전용 라이브 스트리밍 플랫폼**이다. 링크티비의 핵심 기능을 기반으로 하되, UI/UX를 더 심플하게 개선하는 것을 목표로 한다.

### 1.2 핵심 가치
- **심플함**: 불필요한 요소 제거, 방송 시청에 집중
- **개방성**: 별도 심사 없이 누구나 방송 개설 가능
- **접근성**: 로그인 없이도 시청 가능 (방송 참여 기능은 로그인 필요)

### 1.3 서비스 범위 (MVP)
- 실시간 라이브 스트리밍 (시청)
- 기본 채팅 기능
- 이메일/비밀번호 기반 회원가입·로그인
- 카테고리 기반 홈 화면

---

## 2. 사용자 유형 (User Roles)

| 역할 | 설명 | 로그인 필요 여부 |
|------|------|----------------|
| **비회원** | 방송 시청만 가능 | 불필요 |
| **일반 회원** | 채팅 참여, 방송 개설 가능 | 필요 |
| **스트리머** | 방송을 진행하는 회원 (별도 신청 없음) | 필요 |
| **관리자** | 서비스 운영, 신고 처리, 카테고리 관리 | 필요 |

## 3. 기능 정의

### 3.1 인증 (Auth)

#### 3.1.1 회원가입
- **입력 필드**: 이메일, 비밀번호, 닉네임
- **유효성 검사**
  - 이메일: 이메일 형식 검증, 중복 확인
  - 비밀번호: 8자 이상, 영문+숫자 조합 권장
  - 닉네임: 2~20자, 특수문자 일부 제한, 중복 확인
- **이메일 인증**: 가입 후 인증 메일 발송 → 링크 클릭으로 인증 완료
- **미인증 계정 처리**: 이메일 인증 전까지 방송 개설 및 채팅 제한

#### 3.1.2 로그인
- **방식**: 이메일 + 비밀번호
- **기능**: 로그인 상태 유지 (Remember me 옵션)
- **비밀번호 찾기**: 이메일로 재설정 링크 발송

#### 3.1.3 로그아웃
- 세션 만료 처리 및 클라이언트 토큰 삭제

---

### 3.2 홈 화면 (Home)

#### 3.2.1 구성 요소
- **상단 네비게이션 바**
  - 로고 (홈으로 이동)
  - 카테고리 드롭다운 또는 탭 메뉴
  - 로그인 / 회원가입 버튼 (비회원 시)
  - 닉네임 + 방송시작 버튼 (로그인 시)
- **라이브 방송 목록**
  - 현재 라이브 중인 방송 카드 형식으로 표시
  - 각 카드 항목: 방송 썸네일(실시간 미리보기), 방송 제목, 스트리머 닉네임, 시청자 수, 카테고리 태그
  - 정렬 기준: **시청자 수 많은 순** (기본)
- **카테고리 필터**
  - 관리자가 등록한 카테고리 목록 (예: 게임, 음악, 토크, 스포츠, 기타)
  - 선택 시 해당 카테고리의 라이브 방송만 필터링

#### 3.2.2 빈 상태 처리
- 라이브 중인 방송이 없을 경우 안내 메시지 표시

---

### 3.3 라이브 시청 (Watch)

#### 3.3.1 영상 플레이어
- HLS(HTTP Live Streaming) 기반 재생
- 전체 화면 지원
- 화질 선택 옵션 (스트리머 설정에 따라 가변)
- 버퍼링 상태 표시

#### 3.3.2 방송 정보
- 방송 제목
- 스트리머 닉네임
- 현재 시청자 수 (실시간 업데이트)
- 카테고리 태그

#### 3.3.3 채팅창
- 실시간 채팅 메시지 표시 (WebSocket 기반)
- **비회원**: 채팅 읽기만 가능, 입력창에 로그인 유도 문구 표시
- **로그인 회원**: 채팅 입력 및 전송 가능
- **메시지 제한**: 연속 전송 방지 (3초에 1회 제한 권장)
- **채팅 설정 (스트리머)**: 채팅 전체 끄기 / 느린 모드 / 팔로워 전용 모드
- **신고**: 채팅 메시지 우클릭 또는 버튼으로 신고 가능

#### 3.3.4 레이아웃
- 기본: 영상 플레이어(좌) + 채팅창(우) 2단 구성
- 모바일: 영상 상단 / 채팅 하단 1단 구성
- 채팅창 숨기기/보이기 토글 가능

---

### 3.4 방송 관리 (Streamer)

#### 3.4.1 방송 시작
- **방식**: OBS 또는 기타 스트리밍 소프트웨어를 통한 RTMP 스트림 수신
- **스트림 키 발급**: 대시보드에서 개인 스트림 키 확인 (재발급 가능)
- **방송 설정 (방송 전 또는 대시보드에서)**
  - 방송 제목 (최대 100자)
  - 카테고리 선택
  - (선택) 방송 썸네일 이미지 업로드

#### 3.4.2 방송 종료
- 스트리머가 스트리밍 소프트웨어 종료 시 자동 종료 처리
- 시청 화면에서 방송 종료 안내 메시지 표시

#### 3.4.3 스트리머 대시보드
- 스트림 키 확인 및 재발급
- RTMP 서버 주소 안내
- 현재 방송 상태 (라이브 중 / 오프라인)
- 방송 제목·카테고리 실시간 수정 (라이브 중에도 가능)
- 채팅 설정 (느린 모드, 팔로워 전용, 채팅 끄기)

---

### 3.5 회원 프로필

#### 3.5.1 프로필 페이지 (공개, SCR-07)
- 닉네임
- 채널 소개 (자유 텍스트, 최대 300자)
- 프로필 이미지
- 현재 라이브 중 여부 표시
- 팔로워 수

#### 3.5.2 프로필 편집 (본인만, SCR-08)

**편집 가능 항목**
- 닉네임 변경 (2~20자, 특수문자 `<>"'\`` 제한)
- 프로필 이미지 URL 입력 (외부 URL 방식, 실시간 미리보기 제공)
- 채널 소개 수정 (최대 300자, 실시간 글자 수 카운터 표시)

**편집 UI 동작 방식**
- 편집 버튼 클릭 → 모달(팝업) 형태로 편집 폼 표시
- 저장 전 아바타 이미지 실시간 미리보기 제공
- `ESC` 키 또는 오버레이 영역 클릭으로 모달 닫기

**저장 방식 (localStorage 활용)**

| 저장 키 | 저장 내용 | 비고 |
|---------|----------|------|
| `mylink-profile` | 닉네임, 채널 소개, 아바타 URL (JSON) | 브라우저 로컬 저장 |

- 저장 즉시 페이지 내 닉네임·소개·아바타에 반영 (서버 요청 없음)
- 페이지 새로고침 시 localStorage에서 자동 복원
- **RESET DEFAULT** 기능: 저장된 값을 기본값으로 초기화

> [!NOTE]
> localStorage는 클라이언트 임시 저장 방식이므로, 백엔드 DB 연동 후에는 API 호출로 대체한다. MVP 단계에서는 localStorage로 프로토타이핑하고, 이후 `PATCH /api/users/me` 엔드포인트와 교체한다.

**유효성 검사**
- 닉네임: 2자 미만 / 20자 초과 / 금지 특수문자 포함 시 저장 차단 및 오류 메시지 표시
- 아바타 URL: 로드 실패 시 자동 Fallback 이미지(UI Avatars) 적용

---

### 3.6 카테고리 (Category)

- 관리자가 카테고리를 생성·수정·삭제
- 카테고리 항목: 이름, 아이콘 이미지 (선택)
- 초기 기본 카테고리 예시: 게임, 음악, 토크·일상, 스포츠, 교육, 기타

---

### 3.7 팔로우 (Follow)

#### 3.7.1 팔로우 / 언팔로우
- 로그인 회원만 다른 스트리머를 팔로우 가능
- 방송 시청 화면 및 프로필 페이지에서 팔로우 버튼 제공
- 자기 자신은 팔로우 불가

#### 3.7.2 팔로잉 목록
- 내 프로필 / 마이페이지에서 팔로우한 채널 목록 확인 가능
- 각 항목: 스트리머 닉네임, 프로필 이미지, 현재 라이브 여부 표시
- 현재 라이브 중인 채널은 상단에 우선 노출

#### 3.7.3 팔로워 수
- 스트리머 프로필 및 방송 시청 화면에 팔로워 수 표시

### 3.8 검색

> [!NOTE]  
> MVP 범위에서는 간단한 검색만 포함.

- **검색 대상**: 현재 라이브 중인 방송 제목, 스트리머 닉네임
- **검색 결과**: 방송 카드 목록 (홈 화면과 동일한 형식)
- 카테고리 필터 병용 가능

---

### 3.9 신고 및 운영 (Admin)

#### 3.8.1 사용자 신고
- **신고 대상**: 채팅 메시지, 방송, 사용자 프로필
- **신고 사유**: 욕설/혐오, 스팸, 불법 콘텐츠, 기타
- 신고 접수 시 관리자 패널에 기록

#### 3.8.2 관리자 패널 (어드민)
- 신고 목록 확인 및 처리 (경고, 채팅 정지, 계정 정지)
- 카테고리 CRUD
- 방송 강제 종료
- 회원 목록 조회 및 계정 관리

## 4. 비기능 요구사항

### 4.1 성능
- 홈 화면 최초 로드: **3초 이내**
- 영상 재생 시작까지 지연: **5초 이내** (네트워크 환경에 따라 상이)
- 채팅 메시지 전달 지연: **1초 이내** (WebSocket 기준)

### 4.2 확장성
- 동시 스트리밍 수, 동시 접속자 수에 따라 미디어 서버 수평 확장 가능한 구조 설계

### 4.3 보안
- 비밀번호: bcrypt 등 해시 알고리즘으로 저장
- 스트림 키: 본인만 확인 가능, 유출 시 즉시 재발급
- XSS 방지: 채팅 입력 값 Sanitize 처리
- HTTPS 적용 (전 구간)

### 4.4 접근성
- 모바일 반응형 레이아웃 (Breakpoint 기준 768px 이하)
- 기본 WCAG 2.1 AA 수준 권장

## 9. 사용자 시나리오 (User Scenarios)

### 9.1 비회원 — 방송 탐색 및 시청

**시나리오**: 로그인 없이 방송을 찾아 시청한다.

```
1. 사용자가 마이링크 홈(SCR-01)에 접속한다.
2. 현재 라이브 중인 방송 카드 목록이 시청자 수 순으로 표시된다.
3. 상단 카테고리 탭에서 '게임'을 선택하면 게임 카테고리 방송만 필터링된다.
4. 원하는 방송 카드를 클릭한다.
5. 방송 시청 화면(SCR-02)으로 이동해 영상이 재생된다.
6. 채팅창에는 메시지가 흘러가지만, 입력창에는 "채팅에 참여하려면 로그인하세요" 문구가 표시된다.
```

**결과**: 비회원도 방송 탐색·시청이 자유롭게 가능하다.

---

### 9.2 일반 회원 — 회원가입 후 채팅 참여

**시나리오**: 처음 방문한 사용자가 회원가입을 완료하고 채팅에 참여한다.

```
1. 홈 화면 우측 상단 '회원가입' 버튼을 클릭한다.
2. 회원가입 화면(SCR-03)에서 이메일, 비밀번호, 닉네임을 입력하고 제출한다.
3. 입력한 이메일로 인증 메일이 발송된다.
4. 이메일 내 인증 링크를 클릭하면 인증이 완료되고 로그인 상태가 된다.
5. 홈으로 돌아와 방송을 클릭해 시청 화면(SCR-02)으로 이동한다.
6. 채팅 입력창에 메시지를 입력하고 전송하면 실시간으로 채팅창에 표시된다.
```

**결과**: 이메일 인증 완료 후 채팅 참여가 활성화된다.

### 9.3 스트리머 — 첫 방송 시작

**시나리오**: 회원이 처음으로 라이브 방송을 시작한다.

```
1. 로그인 상태에서 우측 상단 '방송시작' 버튼을 클릭한다.
2. 스트리머 대시보드(SCR-06)로 이동한다.
3. 대시보드에서 방송 제목과 카테고리를 설정한다.
4. 스트림 키와 RTMP 서버 주소를 확인한다.
5. OBS를 열고 '설정 > 방송'에 RTMP 주소와 스트림 키를 입력한다.
6. OBS에서 '방송 시작'을 클릭하면 서버로 스트림이 전송된다.
7. 대시보드 상태가 '오프라인 → LIVE'로 변경된다.
8. 홈 화면에 자신의 방송 카드가 노출된다.
9. 방송을 마칠 때 OBS에서 '방송 중지'를 클릭하면 자동으로 방송이 종료된다.
```

**결과**: 별도 심사 없이 스트림 키 발급만으로 누구나 방송을 개설할 수 있다.

---

### 9.4 스트리머 — 방송 중 채팅 관리

**시나리오**: 라이브 방송 중 채팅이 과열되어 느린 모드를 활성화한다.

```
1. 스트리머가 대시보드(SCR-06)의 채팅 설정 패널을 확인한다.
2. 채팅이 너무 빠르게 흘러 '느린 모드(30초)'를 켠다.
3. 시청자는 이제 30초에 1번만 채팅을 전송할 수 있다.
4. 특정 시청자가 욕설을 반복하자 해당 메시지를 신고 처리한다.
5. 방송이 끝나면 채팅 설정을 초기화하고 OBS에서 방송을 종료한다.
```

**결과**: 스트리머가 실시간으로 채팅 환경을 제어할 수 있다.

### 9.5 팔로우 — 관심 채널 등록 및 재방문

**시나리오**: 시청자가 마음에 드는 스트리머를 팔로우하고 다음 방송을 빠르게 찾는다.

```
1. 로그인 회원이 방송 시청 화면(SCR-02)에서 스트리머 닉네임 옆 '팔로우' 버튼을 클릭한다.
2. 팔로우가 완료되고 버튼이 '팔로잉' 상태로 변경된다.
3. 다음 날 마이링크에 다시 접속해 내 팔로잉 목록을 확인한다.
4. 팔로우한 스트리머가 현재 라이브 중이면 목록 최상단에 표시된다.
5. 해당 항목을 클릭하면 바로 방송 시청 화면으로 이동한다.
```

**결과**: 팔로우 기능으로 관심 스트리머의 방송을 빠르게 찾을 수 있다.

### 9.6 프로필 편집

**시나리오**: 회원이 닉네임과 채널 소개를 수정한다.

```
1. 로그인 상태에서 내 프로필 페이지(SCR-07)에 접속한다.
2. '프로필 편집' 버튼을 클릭하면 편집 모달(SCR-08)이 열린다.
3. 닉네임 입력란에 새 닉네임을 입력한다. (2자 미만이면 저장 차단)
4. 채널 소개를 수정하고 실시간 글자 수 카운터로 300자 이내임을 확인한다.
5. 아바타 이미지 URL을 입력하면 미리보기 이미지가 즉시 변경된다.
6. 'SAVE PROFILE'을 클릭하면 변경 사항이 localStorage에 저장되고 즉시 반영된다.
7. 페이지를 새로고침해도 수정된 프로필이 유지된다.
```

**결과**: 별도 페이지 이동 없이 모달에서 빠르게 프로필을 수정할 수 있다.

### 9.7 관리자 — 신고 처리

**시나리오**: 관리자가 접수된 채팅 신고를 처리한다.

```
1. 관리자가 어드민 패널(SCR-10)에 로그인한다.
2. 신고 목록 탭에서 처리되지 않은 신고 건을 확인한다.
3. 신고 내용(욕설)을 검토하고 해당 회원에게 '채팅 7일 정지' 조치를 취한다.
4. 조치 완료 후 신고 상태를 '처리됨'으로 변경한다.
5. 반복 신고 회원은 '계정 정지' 처리한다.
```

**결과**: 관리자가 신고 건을 중앙에서 효율적으로 처리해 건전한 채팅 환경을 유지한다.
